# 疾风原机制选关

只加载疾风竞技场（真实模式6）。目录按实际第1～8关合并完整路线与原传送符路线，包含30张地图、238个普通板子位置、509种不同版型；第8关另有20种无限段版型。关级、地图池、每个位置的版型池及权重均来自当前客户端配置。

## 定位方式

跳关调用原SetEndlessSkipLevelInfo，保留原跳关距离和分数初始化。地图由原生成器完整构建，只固定所选地图和候选版型，未指定位置仍使用原池。不会删除前面的板子、强行改出生点或补发GameStart事件。

板内定位调用原通灵兽RushAtGameStart。Boss/循环段会动态延长，因此等原引擎真正生成目标板子后读取StageStartX，通过原CurrStartRushRemainDis结束冲刺，再沿原运动到达目标板子的首次可着地点。完成时检查角色脚下的原BelongToStageIndex、实际版型、生命和落地状态，底层接口随后暂停，交互菜单会自动恢复游戏，无需再按一次P。Boss和奖励过程保留，后半段定位可能需要数分钟，并非即时传送。

落地后只回收本次新增的角色来源buff，保留之前已有的buff及场景/陷阱来源buff；原定时无敌自然消退，不直接清零计数器。不会为了保证无伤而关闭陷阱或补血。不能保证每种版型入口都能在第一个像素无伤开局；若始终无法在所选板内着地，会返回错误，不能把到达其它板子当成功。

竞技场Boss在原正式开战时通过原属性和阶段血量接口设为1/1，原AI、受击和死亡流程保留。5000血为基础小黑初始血量，定位途中真实伤害仍会扣除。

## 训练接口

```python
from arena_env import ArenaEnv

env = ArenaEnv(auto_start=False)  # 先通过tools/run-arena启动
obs, info = env.reset(seed=42, level=3, map_id=24,
                      start_board=6, boards={6: 31062})
obs, reward, dead, truncated, info = env.step('jump', ticks=8)
```

提供map_id且省略chapter时，level是菜单中的实际关级；例如第3关map24自动使用原chapter3/level1。显式chapter非1时使用原路线索引。boards为「位置:版型ID」；无限段是普通位置数+1，仅选择首次进入的循环版型池。reset同步等待定位完成，返回原1280×720画面并隐藏训练菜单；出错不会继续旧回合。

## 板子标注和验证边界

“随机分布”表示该版型内部有怪物位置范围、块组候选或重复次数等配置随机项。“固定布置”表示未发现布置随机配置，不表示所有AI都确定；随机转向/转速另标“动作随机”。每个位置随机抽取哪种版型，与某个版型内部是否随机是两件事。

实机验证包括普通地图指定板子、同位置切换版型、原传送符专用地图、第8关无限段、Boss循环后短平台/落差入口、落地保护消退、原按钮/键盘和训练step。未逐一穷尽509种版型的所有随机结果。重复种子的地图对照保留完整顺序、几何、敌人、物品与事件；已生成敌人的运行等级会由原引擎改写，导出没有伪装成不可变静态数据。

陷阱排查与重开池对象回收见[记录](../.mr3a-records/archived/2026-11-09-arena-reset-object-recycling.md)。训练仍使用原客户端引擎；当前不承诺逐像素确定性，也尚未训练视觉策略。
