# 情报模拟战离线组合模拟

本工具只做统计与性能试验，不导入Maa/ADB/实例管理，不修改当前选牌逻辑或运行任何游戏。牌库来源见[规则与完整牌库](../../.mr3a-records/archived/2026-11-15-intelligence-rules-and-cards-study.md)。

## 计算的对象

从53种/81张原始牌库扣除自己场上牌、显式给出的已知不可用牌；不猜测对手持牌。在当前金币及空格限制下枚举**所有买得起的牌种多重集**，不限制为商店5张，也不枚举下牌操作顺序。每组牌尝试所有合法落位（同种两张不重复交换身份），取该组最优落位的伤害。

收益为固定这批牌和位置、不再追加购买时，从当前回合到第5回合的理论累计伤害。既报`total_damage`，也报相对不买牌基线的`damage_gain`，不能混读。不推演对手血量/提前结束。空购买组合纳入统计。

- `unique_combinations`：每个不同的牌种多重集等权。
- `physical_subsets`：该组权重为各牌种`C(剩余张数, 购买张数)`之积，相当于每个合法实物子集等权。
- 二者都是合法组合的统计口径，**不是商店抽牌概率或真实策略胜率**。
- 平均数、中位数、P10/P90、最小/最大、标准差分别计算。直接胜利组合单独计数，不以无限伤害污染均值。

## 模型边界

四向相邻和入场效果仅当回合生效由用户确认；入场伤害统一按最终棋盘计算，故同一回合操作顺序无关。其余尚未实测的机制显式采用假设：持续2回合包含放置回合、先加法/光环再乘法再额外伤害、种类计数不含灰色无属性、每上场可包含自身和同时放下的卡。

默认`since_entry`仅计来源牌入场当回合及之后上场的牌；`--growth-mode board_count`可改为当前场上总数做敏感性对照。这些是计算模型，不能称为已验证游戏公式。`entered_round`用于入场效果、临时效果和上述触发计数，旧牌的额外历史永久加成可填`intrinsic_bonus`。

计入不再购买时的后续回合收入、少买奖励、黑卡/御守和猫太第五回合存钱伤害；轮回额外刷新不转换成虚构未来购买收益。该指标会偏好存钱路线，不能直接当实战决策价值函数。

## 使用

需要本地Python及支持C++17的g++/clang++。Python负责局面、精确组合计数、抽样和统计，C++ `-O3`负责落位/回合计算；首次编译到系统临时缓存，后续复用。没有联网安装依赖。输出分别记录准备、编译、核计算和原生调用墙钟耗时。

```bash
# 只计算全量规模，不搜索位置
python tools/intelligence_pool_sim.py tools/intelligence_simulator/scenarios.json --count-only

# 全量搜索，每个局面计算核最多2秒
python tools/intelligence_pool_sim.py tools/intelligence_simulator/scenarios.json --seconds 2 --output /tmp/pool.json

# 单独算完整开局5金币（本机约24秒）
python tools/intelligence_pool_sim.py tools/intelligence_simulator/scenarios.json --name empty-r1-g5 --seconds 50 --output /tmp/pool-g5.json

# 对整个合法实物子集空间均匀抽样，再对每组精确求最优落位
python tools/intelligence_pool_sim.py tools/intelligence_simulator/scenarios.json --name empty-r1-g8 --samples 128 --physical-sampling --seed 20261115 --seconds 15 --output /tmp/pool-sample.json
```

局面文件可为单对象或数组，例如：

```json
{
  "name": "three-tigers",
  "round": 3,
  "gold": 5,
  "board": ["神乐·琳", "鬼狩·苍牙", "雷兽·阿力", null, null, null, null, null, null],
  "known_unavailable": {"怒鲤双生": 1}
}
```

棋盘按从左到右、从上到下排列。字符串形式默认第一回合入场；更精细可写`{"name":"樱火·茜","entered_round":2,"intrinsic_bonus":0}`。`pool_override`用于受控小牌库试验，仍不能超过扣除已知牌后的真实张数。不输入对手信息。

## 完成与截断

- 完整穷举才有`statistics`且`all_combinations_evaluated=true`。
- 预算耗尽的确定性前缀只有`partial_prefix_statistics_not_pool_estimate`，不冒充全池均值/中位数。
- 随机样本只有`sample_estimate`、采样分布及均值标准误，`all_combinations_evaluated=false`；`complete`只代表所请求样本是否全部完成。
- `coverage`是实际覆盖的不同牌种组合比例，采样完成不等于全空间覆盖。
- `linear_full_runtime_estimate_s`只是按已处理落位速度外推，不是全量完成实测。
