# 竞技场本地模拟器

这是可直接操作的原生桌面练习台。地图和小黑序列化参数来自本机官服客户端；物理状态机及障碍碰撞是待实机校准的初版模型。第一版用于观察地图、练习动作、记录输入并调节模型，不能作为自动竞技场策略已可上实机的验收依据。

## 启动

已提取资源的本机直接运行：

```bash
./tools/run-arena-simulator
```

入口从项目根解析路径，可在其它工作目录调用。依赖位于独立工具环境；重新安装时：

```bash
python3 -m venv debug/arena-client/toolenv
debug/arena-client/toolenv/bin/pip install -r tools/arena-simulator-requirements.txt
```

默认读取 `debug/arena-client/dataset/` 和 `debug/arena-client/xiaohei/`，可用 `--dataset`、`--physics` 指定另一份已提取数据。资源取得方式见 [客户端数据提取](竞技场客户端数据.md)。原始客户端资源与提取密钥均未入库，换机器需自行重新提取。

```bash
./tools/run-arena-simulator --mode training
./tools/run-arena-simulator --mode endless --stage 1038
```

窗口默认在准备状态，按 P 开始跑动，空格可直接开始并起跳。所有操作也有界面按钮。可切换动作实验场、Endless、Endless_Gale、SingleEndlessReserved1 三套原始资源池；原始1493 Stage中1491段有可跑的地形，扩展池的190/3093是空段，选图自动过滤但保留源文件。

## 操作

| 操作 | 按键 / 鼠标 |
| --- | --- |
| 起跳 / 二段跳 | 空格、W、↑；画面左键或跳跃按钮 |
| 下翻 / 地面下闪 | S、↓；右键或下翻按钮 |
| 开始 / 暂停 | P；Esc只暂停 |
| 重开本段 | R |
| 从当前地形块检查点重开 | C |
| 上一段 / 下一段 | B / N |
| 选图与搜索编号 | Tab，输入数字，Enter；滚轮翻页 |
| 无敌练习 | H |
| 显示碰撞框 | F |
| 时间倍率 | − / +，0.25～2倍 |
| 画面缩放 | 滚轮 |
| 保存操作记录 | F5 |

右栏滑块可覆盖水平速度、两段跳参数和第一段上升/下降重力，支持拖动。水平速度为0时按当前块的 `_ninjaSpeed`，缺省才回退角色 `_moveSpeed`。「恢复提取值」恢复载入的小黑原值，不写回客户端文件。当前调整不跨启动持久化；F5记录会保存当次参数。

F5输出 `debug/arena-client/simulator/run-时间.json`，包含段落来源、模型参数、操作时间、是否接受动作和最后状态，供后续本地策略与实机对照使用。此版本提供输入记录，没有宣称实现跨版本精确回放。

## 已接入与近似范围

- `arena_model.py` 是无设备依赖的纯本地状态模型；`arena_simulator.py` 只处理本窗口的 Pygame 事件。模拟器不导入Agent、ADB或Waydroid控制模块。
- 从角色导出中按实际 `Ninja`、主 `NinjaCollider` 指针和根 Transform读取参数；排除分身和坐骑碰撞。小黑基础模型限两次跳跃，不因资源包含3/4段字段就开放额外跳跃。
- 从 Stage读取地形起止、分段速度、障碍/物品局部位置、缩放、旋转和自定义数据。坐标按首个实体地形起点统一平移，不压平地形高差。元数据枚举核实 GroundType：line=0、ground=1、fever=2、link=3，link不生成假地板。
- 固定1/120秒模型步长，渲染帧率独立；暂停不积累移动时间。记录跳跃/下翻，显示金币、碰撞次数、速度、坐标、纵向速度、轨迹及全段缩略图。
- UI的「动作实验场」是明确标识的本地生成场景；其它模式使用原始 Stage，不把测试场地伪装成客户端关卡。当前为单段练习，下一段按编号切换；**没有复现服务器一局随机路线/种子或Boss流程**。
- 原始配置被用作当前模型参数，但尚未核实客户端的积分顺序、状态时间、天赋/活动/Lua覆盖、根缩放运行时重设、输入缓冲及延迟。当前模型假设 jumpForce 作为起跳速度、二段重设纵向速度、分段重力，不能将由此算出的跳高和滞空视为客户端实测结果。
- 翻绳使用配置地面/空中速度向绳两侧移动，地面下闪持续0.35秒、翻绳过渡0.24秒均为**模型设定**，并非从客户端读出的时间常量。攀爬、特殊地形、斜坡阻挡和受击状态尚不完整。
- 敌人用简化圆/菱形/刀轮碰撞表示，半径为模型近似；部分带显式参数的弹道使用速度/重力。未复现完整行为树、生成间隔、曲线、激光、Boss、伤害/技能/得分规则。物品除普通金币外仅做标记，不能据此判定正式通关。

## 验证

```bash
PYTHONPATH=agent .venv/bin/python -m pytest tests/test_arena_client.py tests/test_arena_model.py -q
./tools/run-arena-simulator --headless --smoke --frames 350 \
  --capture debug/arena-client/simulator/interactive-preview.png \
  --state-output debug/arena-client/simulator/interactive-smoke.json
```

`--smoke` 通过实际Pygame事件队列测试键盘、鼠标按钮、选图搜索、滑块与记录保存，会在本地生成一份测试操作记录。`--headless` 使用SDL dummy显示；`--frames`限制渲染帧数，`--capture`输出PNG。正常运行无需这些参数。桌面窗口可能按窗口管理器布局调整大小，程序使用实际窗口尺寸。
