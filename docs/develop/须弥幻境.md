# 须弥幻境

限时活动任务，从集会所进入，完成并领取每日任务。独立入口：

```bash
./tools/run-xumi [实例名字] --once
# 等价于 ./run [实例名字] --task 须弥幻境 --once
```

省略名字为main，共用程序和源码，沿用该账号自己的角色、队伍和难度。独立入口仅选择本活动，适用于游戏已启动的环境；冷启动需要登录时可用 `./run [名字] --task 启动游戏 --task 须弥幻境 --once`。任务在「限时活动」列表中可配置，限时活动预设默认不勾选；单次入口不覆盖保存计划。每天四项全部领取后禁用到下一05:00。

进入活动后打开右上角「每日任务」。先领取可领奖励，再分别检查「完成/挑战一次方寸试炼」「完成/挑战一次大千试炼」以及两种试炼的累计积分任务。哪种试炼仍有未完成进度就进入对应试炼，点击开始游戏，挂机等待第一场结算；点击「继续试炼/继续挑战」进入第二场，再挂机等最终结算，点击「返回须弥幻境」。游戏实际先回到试炼选择页，脚本再返回活动首页重新检查任务。积分不足会重复相应试炼，不因为完成一次就登记整项完成。

战斗不释放技能，不调整难度、额外选项和角色队伍。出现「选择忍者接力」时只点跳过，不花费接力货币。一键领取后的奖励确认完毕，只有四项都明确显示「已领取」才回游戏主页、写入每日完成状态并停止本任务。

## 流水线与识别边界

业务步骤、OCR、点击、等待、领奖及持久化都在 `assets/resource/pipeline/须弥幻境.json`。集会所卡片在整片卡片区域查找，实机OCR「须称幻境」兼容为同一入口；艺术字试炼入口使用已确认活动首页内的左右入口区域，试炼选择页再用标题验证。实机「大千試炼」的繁简写法也接受。

每日任务会按可领取/未完成/已领取重新排序。原生OCR读取四条任务内容，`BindXumiTaskRows` 只将这些文字的行坐标绑定给同行的「已领取」和数字进度OCR节点；不自行截图、OCR或点击，不保存一份可能与游戏不同步的分数。缺少任一任务、出现同类歧义或行位置异常时拒绝推进，避免把别行已领取当作完成。

导航在加载黑屏中等待识别，不盲点返回。沿用命名实例、闪退恢复、网络重试和游戏重启更新分支；总时限一小时、单场等待上限十二分钟，超时交给重启恢复，不登记完成。原生超时截图保留在该实例的 `debug/loop_deadline_expired/`。
