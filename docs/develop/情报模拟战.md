# 情报模拟战

任务注册在「限时活动」，预设默认关闭，不改现有账号计划。界面操作均在`assets/resource/pipeline/情报模拟战.json`；不新增Python截图/点击/战斗控制器。

实机环境就绪后可用原命名入口（本轮未执行）：

```bash
./run main --once --task 情报模拟战
```

仅在北京时间10:00≤当前时间<14:00或18:00≤当前时间<22:00进入任务；其它时间用现有ScheduleDeferredTask挂起到下一10:00或18:00。单次模式沿用原约定，未来时段返回deferred/3。已结束的对局先处理结算、检查每日任务，再决定是否继续匹配，不在对局中途因过点退出。

从主页进入集会所，OCR查找活动卡片，必要时有界横向翻页。首次教程沿用原生「下一页/我知道了」和点击空白关闭的识别方式。进入活动大厅先打开右上活动任务、选择每日任务；先领取可领奖励，再判断状态。每日状态列须非空、只出现「已领取」，未完成/可领取/未知文字均不会直接登记完成。确认完成后回游戏主页，再按next_daily_reset禁用至次日05:00；未知页面或无法确认时走错误恢复。

每局点击开始匹配，等待倒计时与第1–5/5回合文字。每个回合编号只初始化一次；倒计时短暂识别失败需连续两帧确认，不单凭一次miss切轮。右侧五个槽位分别OCR角色名后缀，接受小黑、苍牙/仓牙、琳、阿力、小椒，不依赖前缀。选中后拖至左侧模板识别到的空格，不对已占格盲放；每个槽位每轮至多尝试一次，金币不足或拖放失败不会无限重试。第一轮看完后刷新一次，再看第二轮，点击准备就绪。回合编号变化会切换到新回合，防止上一回合动作串入下一回合。格子满或没有目标卡片也会继续刷新/准备。结算确认后重新检查每日任务。

整个任务上限一小时、单局上限15分钟；超时走失败/恢复，不写完成状态。保留同名实例控制互斥和原有单次退出协议。

## 当前离线验证边界

仅有用户提供的选牌截图，已归一到1280×720作为离线fixture；原生OCR可识别倒计时、回合（斜杠实测误读成1，已兼容）、空位与截图内的小黑/小椒，并排除云狐/梵天/轮回之戒。纯内存CustomController回放四次拖放（两轮各两张）、刷新一次、准备一次，未连接ADB或实例。

以下须等用户提供实机环境后校准，不能认为已经验收：

- 集会所卡片所在页、横向翻页方向及首次教程的实际布局。
- 活动任务窗口、每日页签、状态列和领奖/关闭按钮；确认是否存在滚动列表。若任务不全在一屏，需补全页扫描后才能验收「全部已领取」。
- 实际拖放是否成功入格、扣币/满格/合成规则，刷新是否确实生效。
- 回合转换、真实结算标题/确认按钮，以及连续多局的领奖与持久化完成。
