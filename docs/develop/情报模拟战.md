# 情报模拟战

任务注册在「限时活动」，加入「日常任务」预设并排在3v3前；限时活动预设仍保持显式关闭，避免额外启用整组活动。main保存队列同样排在3v3前。沿用命名实例，也可临时运行：

```bash
./run main --once --task 情报模拟战
```

北京时间10:00≤当前时间<14:00、18:00≤当前时间<22:00开放；其它时间挂起到下一10:00/18:00，单次模式返回deferred/3。对局结束先确认结算并检查每日奖励，再判断是否继续匹配。每日任务是活动任务面板上方固定两条，分别确认「已领取」，不包含下方成就；完成后回主页，持久化禁用到次日05:00。

任务选项「无限打」（内部名`情报模拟战无限打`）默认关闭；开启后仍先领取每日奖励，两条全领取后关闭面板、重新检查活动时间并继续匹配，不登记今日完成。main目前已保存为开启，下次启动加载；其它实例未更改。它只取消每日完成出口，仍保留活动时段、任务1小时/单局15分钟超时保护；单次模式也不会因每日全领取返回完成。需要正常完成退出时把该选项关闭。

界面导航、教程、识别、点击、刷新、准备和领奖均在`assets/resource/pipeline/情报模拟战.json`。每回合只做两轮选牌，第一轮之后刷新一次，第二轮之后准备。五回合通过编号与原生max_hit去重，每局重置；倒计时短暂消失不会重新开始同一回合。重启测试时可从已确认的对局页面接回等待，不需要退出对局。

每手由原生批量OCR读取完整卡名、金币、剩余刷新次数和对手血量，消费空位识别结果；Agent调用`agent/intelligence_strategy`共用策略，枚举本手所有买得起的组合及合法空格落位，按当前棋盘累计至第五回合伤害＋被动/空位潜力＋分阶段留金/产币价值统一比较。不抽样后续发牌，不先截取6组，也没有随机续局推演。可在当前回合击杀时始终优先击杀，不为第五回合账面收益拖延。未知卡名不猜变体，剩余未知商店槽仍计入刷新机会。翻牌期间等名称带恢复，刷新后不会无限重试刷新。

取消提前占位扣分后，按独立回归校准金币价值：第1～5回合刷新前为12/9.6/7.2/4.8/2.4，刷新后为8/6/4/2/0；空位buff潜力权重仍为1，没有新增占位惩罚。校准过程与未达目标见[金币重标定](../../.mr3a-records/archived/2026-11-15-intelligence-gold-no-slot-recalibration.md)。

点击、放置、刷新、准备与结算仍是原生JSON节点，Python不截图、不OCR、不直接控制设备。点击队列结束再读原生回执：金币扣除、目标格非空、原商店槽消失三者对应后才登记卡牌；失败点击不虚构战力。每实例`data/intelligence-battle-state.json`保存本局已确认棋盘和待确认动作。正常规划日志mode为scored；未知旧局/状态矛盾降级为受金币和已识别空格约束的保守选择，下一新局恢复正常。血量未知的后期回合优先当前伤害；金币未知不盲买。

匹配前只预热本手组合/落位枚举的C++17核，正常选牌不承担首次编译耗时；本机使用g++，编译不可用会明确记录降级。`tools/intelligence_simulator`只是共用策略的兼容导入入口，不复制实现。正在运行的Agent不会热加载Python修改，下次启动使用新版本。

结算用「当前积分＋剩余血量＋确定」定位；每回合的临时战斗结算没有当前积分，不会误点。整个任务上限1小时、单局15分钟；无法确认完成或超时走失败恢复，不写完成状态。
