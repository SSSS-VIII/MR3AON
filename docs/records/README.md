# 项目记录导航

这里保存帮助理解 MR3A 和继续开发的上下文，不是逐提交日志。具体代码变化优先查 Git，当前行为以代码和实际验证为准。

| 文件或目录 | 主要内容 | 何时查阅或更新 |
| --- | --- | --- |
| [workflow.md](workflow.md) | 开发与运行链路、分支习惯、重要技术约束 | 工作方式或接口边界发生变化时 |
| [current-work.md](current-work.md) | 当前进展、阻塞、待验证事项和专题入口 | 开始相关工作、阶段交接或状态变化时 |
| [roadmap.md](roadmap.md) | 方向、优先级与阶段目标；也保留早期进度 | 确定下一步或目标发生变化时 |
| [test-environment.md](test-environment.md) | 命名实例、账号隔离、工具与验证环境 | 操作实例前；环境用法变化时 |
| `archived/` | 专题调查、设计取舍、故障依据、阶段验证 | 当前摘要不足以解释问题时按主题查阅 |
| `benchmarks/` | 模拟与回归的结构化数据 | 对比策略成绩、复现已有实验时 |

先读当前任务需要的摘要，再按关键词、文件路径或相关提交定位专题，不要求每次按固定顺序通读所有记录。

记录按主题组织，优先更新已有内容。代码和 Git 已能清楚表达的小改动无需另建记录；同一方向的多次试验可以累计整理，保留有用依据与未解决问题即可。没有“一次提交一篇记录”、固定模板或所有操作都留痕的要求。提交或交接时自行判断哪些信息值得长期保存。

本目录原为仓库根的 `.mr3a-records/`（也曾被简称 `.mr3a_record`），现统一为 `docs/records/`。旧归档中的命令、绝对路径和规则文字保留历史语境，不是现行指令；尤其逐提交强制归档和 Cursor 规则已废止。现行协作入口为根目录 [AGENTS.md](../../AGENTS.md)。不为目录迁移重写实验原始数据或重造一套历史记录。
