# 小鲤网络异常后重启实例

## 需求 / 现象

用户在 OPPO 账号入口排查期间反馈网络不通，要求先重启。中止继续切换登录页面，优先处理 xiaoli 的 Android 重启与网络检查。

## 操作与原因

- 通过 `InstanceSession('xiaoli')` 取得控制租约停止 Android 会话。旧 ADB 连接已经不存在，disconnect 返回 no such device，使 restart 后半段没有自动执行；确认停止已发生后，继续调用 ensure_ready 完成同名 Android 启动。
- 未重启主环境、修改账号配置或清理应用数据。没有尝试填写手机号、密码或提交登录。

## 验证 / 边界

- xiaoli 已重新启动，就绪检查通过，设备地址仍为独立子网的 192.168.242.112。
- 从 Android 内 ping 223.5.5.5：2 发 2 收、0% 丢包。
- www.oppo.com 成功解析并 ping 通：1 发 1 收、0% 丢包。证明当时外网 IP 与 DNS/ICMP 连通，不将其等同于所有账号接口均可用。
- 本次为设备操作记录，无源码改动。stop 对已消失 ADB 连接的容错仍可另作修复；未为此重启请求扩展改代码或运行无关测试。手机号密码登录入口尚未完成确认。
