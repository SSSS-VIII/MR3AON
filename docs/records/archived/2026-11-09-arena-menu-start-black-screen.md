# 选关开始后的黑屏与页面实现说明

## 用户反馈与复现

用户实际点击「定位到第1块」后黑屏；同时明确不需要页面上「原版传送符/通灵兽/回收保护/不裁剪」等实现说明。不能用之前状态接口为Game8或单测通过替代真实点击/画面验收。

在用户选择的第7关map61/7001复现：底层reset在Game8/Running、约21物理步时暂停，此时入场画面仍几乎全黑；保持TimeScale0一秒，黑幕不结束；恢复TimeScale1后0.6秒可见原地图和角色。旧菜单按钮只发起一个最终保持暂停的训练任务，完成后又展示暂停菜单，要求用户另按P；这一交互导致入场过渡被暂停，不能把它当作正常「开始」。原始图paused-first-board*.png、resumed-first-board.png及点击时序在忽略目录gameonly/menu-black-screen。

反复重开诊断中还实际遇到WaitGameStart不进入Running、最终角色死亡的失败任务。此次补齐客户端原RecycleLevel中的完整回收顺序，不直接修改GameStart、出生点或陷阱。

## 改动

- 菜单发起的任务单独保存pendingStart，成功后仅一次自动恢复游戏并关闭自己的Canvas；不再需要第二次按P。训练API没有此标记，仍保持暂停契约。未完成/失败任务不恢复运行，失败时保留选关入口；加载中重复点击忽略，不替换正在运行的任务。
- 「定位到…」改为「从第…块开始」，「从头开始」作为开头入口。删除页面中全部原机制、资源、裁剪和buff实现说明。保留关卡/地图/有序板子/版型及随机标注、种子和简短按键。加载只显示「加载中…」与目标关卡/板子，使用小卡片，避免大面积说明层遮住游戏。
- 原重开顺序原先只回收Item/Enemy；现按原生PUGCManager.RecycleLevel的通用清理部分依次调用RecycleAllBlock→ClearAllActiveItem→ClearAllActiveEnemy→SpawnPool.DespawnAll→RecycleAllMainAirGround，再销毁旧Scene/更换GameInfo。覆盖地块拥有的事件、平台和池特效，不给单个陷阱加行为补丁，不强行StartGameContent。原原生调用链与字段探针只留忽略目录。
