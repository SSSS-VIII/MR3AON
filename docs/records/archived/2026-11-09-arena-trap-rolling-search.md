# 矩形机关使用已有滚动动作规划

## 原因及改动

八类v4隐藏爪识别与短时中心预测已校核，原短时策略仍在二段跳后落入后续机关。此前MPC仅用于弹球和已学得飞行状态；现在trap也接入同一矩形扫掠及原动作搜索，不引入板号、特权状态或新游戏机制。地面仍走原支撑/跨缺口处理。

## 验证及限制

56项针对回归通过。claw-mpc64/65三板均完成，总伤害575.96/623.96，其中隐藏爪335.96/503.96；同八类权重旧策略claw-live64/65隐藏爪均约588。这只是两轮，不能称稳定改进或全无伤；受伤及当前源摘要保留。

进一步原生动作探测发现空中下翻确实可用：四种一/二段跳中按原UI下翻后，下一帧进入rollToLineDown。现规划器未允许该动作，属于动作集合缺项，后续按原生实测轨迹补齐，不能靠缩短冷却或改怪物规避。
