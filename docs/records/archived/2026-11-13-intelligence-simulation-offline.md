# 情报模拟战原生流水线离线开发

## 需求与约束

新增集会所「情报模拟战」。10–14、18–22开放，其它时段挂起；首次教程按既有下一页/我知道了/空白关闭方式处理。每日任务全部已领取后结束、禁用到次日。每回合选小黑/仓牙/琳/阿力/小椒，放九宫格空位，刷新后再选一轮并准备；结算后复查任务。用户明确本轮没有运行环境，禁止启动或操作任何实例，稍后再给实机条件。

已交叉阅读开发记录、Git语义、工坊原生教程/超时、现有时间识别与调度/持久化实现和Maa本地协议。未启动、截图或操作main/xiaoli/arena等任何实例；只使用附件静态截图与纯内存控制器。

## 实现

新增情报模拟战.json，导航、教程、活动任务/领奖、选牌、刷新、拖放、回合与结算全部使用原生流水线。复用TimeAfter/TimeBefore、ScheduleDeferredTask每日10/18点、ResetCount/Count、NodeOverride、LoopDeadline和SetManagedTaskPersistentState，无新增Python界面控制器或后台输入线程。

时段为[10,14)、[18,22)，过点不打断在局战斗；结束先查领奖，再决定继续或挂起。完成状态只从已确认每日状态列、排除其它文字并返回主页后登记，延后不是完成。次日沿项目规则05:00恢复。整个任务1h、单局15min超时不登记完成。

右侧五槽位后缀OCR接受苍牙和用户写法仓牙；每槽每手只尝试一次，使用显式命名的Count额度节点，避免And内联识别名称与ResetCount不一致。空格模板取自附件，拖放使用And.box_index选择空位、Swipe.begin固定对应槽位、end=true指向识别到的空格。刷新前后两套选牌分支，刷新一次，再准备。回合编号1–5各只初始化一次，当前编号与其它编号由NodeOverride更新；两次倒计时消失检查防瞬时miss，编号变化避免旧阶段继续输入。

任务注册在限时活动，预设关闭；现有账号配置/计划没有修改。用法和校准项写docs/develop/情报模拟战.md。

## 离线验证

- 专项19项通过（20.52秒）：10组开放边界/下一时段、非空/未知状态拒绝完成、任务可选且不改配置、两手牌/回合与持久化保护。
- 原生资源/真实附件OCR回放：倒计时44s、空位命中；五槽位命中[true,false,false,false,true]，选小黑和小椒而不选云狐/梵天/轮回之戒。实际回合OCR为「第115回合」，已兼容斜杠读1。
- 纯内存CustomController真实执行原生Swipe，确认从右侧拖到左侧识别空位；模拟Count额度消费/重置，单回合四次拖放、刷新一次、准备一次。模拟控制器不等于游戏内购买/放牌成功，未连接任何设备。
- 扩展任务参数/状态/队列回归40通过、3子断言通过；另3项旧SchedulerOverride精确字典断言不接受enable/enabled双写而失败，均使用自己fixture、与本次新增资源无关。未删除有历史依据的双字段兼容，也未把该组写成全绿。
- 原生资源整包加载、git diff --check通过。没有运行./run、Waydroid、ADB或任一实例。

## 实机待验

附件只覆盖选牌页。集会所入口、教程、活动任务页布局/状态列/是否滚动、实际刷新和拖放入格、结算确认及多局领奖/每日禁用尚未验收。任务页若存在多屏，必须实机补全页扫描，不能只用一屏已领取判全量。默认不自动开启，等待用户提供环境后继续，不能以离线控制器代替这些验收。
