# 配对采集复用原生指定位置跳板

## 需求与错误校核

隐藏爪独立检出率低，需要采集原生多姿态数据。初次误把第一位置11011当作隐藏爪板；paw56及中断paw58原对象统计只有蜘蛛，已停止队列，明确不作为隐藏爪训练数据。按完整疾风placements目录核实，EnemyHidePaw为类型113，地图1第三位置11031有41份放置引用。

## 改动

prepare增加默认1的start关键字，实时完整跑图默认行为不变；配对采集CLI的--start将位置与board pin一起传给原native_select，复用原传送/通灵兽流程，不外移角色或删场景。setup保存采集及准备代码摘要、原生初始板号/序号，便于查错。
