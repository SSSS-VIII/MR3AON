# OPPO 冷启动可币券弹窗

## 现象与原因

开发每日悬赏拉小号时，xiaoli冷启动停在OPPO「可币券秒杀」弹窗，尚未出现游戏登录按钮。原启动流程的游戏叉号模板与原生渠道弹窗的细线叉号不匹配，导致小号准备超时。

## 改动

启动登录检查前新增专门关闭节点。联合识别弹窗标题和右上细线叉号，仅点击叉号命中框。支持两种实际显示尺寸，不点击优惠券或支付按钮，不修改包管理器Waydroid、渠道账号或持久配置。
