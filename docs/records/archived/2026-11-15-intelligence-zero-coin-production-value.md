# 产币效果未来评分归零并删除经济倍率

## 需求与原因

用户明确指定产币价值为0，并否定额外经济权重。此前御守未来产币按金币价折42分后乘2为84分，压过其它当前收益。本次按要求删除这一整段估值，而不是仅把倍率由2降为1。

## 改动

- tuned删除income_weight配置及未来属性增长、消费容量、产币折价循环，所有候选income_potential固定0作为报告兼容字段；评分只保留模型伤害/被动/空位潜力和当前剩余金币价值，仍优先本回合击杀。
- 御守/黑卡自身攻击、属性或对其它牌的协同仍正常计算。环境真正产出的金币及回合发放收入不抹除，单边回归按真实收入更新下一轮可用余额；这是已到账预算，与不再估值的未来产币分开。
- 当前金币价表12/9.6/7.2/4.8/2.4及8/6/4/2/0未改；不加占位罚分、不恢复随机续局，不改原生核协议或实际点击。
- 单边报告标记current-hand-v6，开发文档同步。旧金币调参时保留的经济倍率2已不存在，其旧成绩不冒充当前新策略效果。

## 验证

实际18:32御守手牌场景回归：洛青在场、3金币、已刷新，候选金刚覆面/龙焰小黑/御守；去掉产币84分后选择金刚覆面，所选收入潜力为0，分数为伤害潜力加当前留金币价值；旧income_weight参数拒绝，不能再悄悄开启倍率。
