# 用全牌库组合数据估计金币参考价

## 用户要求与修正

用户要求利用此前已经跑过的全牌库策略数据整理金币价值，不停留在概念解释。上一版使用的是单张补牌单位增伤中位数（空盘第1回合4点/金），没有充分使用全池组合数据；本次明确改为整理整池可买组合的平均金币效率，作为可替换参考表，不擅自宣称它已是最优权重。

本次纯离线，未运行任何实例，未修改Agent/流水线，未改变累计到第5回合的目标，也未修正早100偏差。

## 统计口径

每个可买组合先取最优落位，累计当前至第5回合的伤害，减去不购买时既有棋盘伤害，得到增伤。组合按各牌种剩余份数的组合数之积加权，沿用此前实物子集口径。

金币参考价 = 同口径加权总增伤 / 同口径加权总实际花费 = 平均增伤 / 平均实际花费。

不拿当前预算代替真实花费，也不把旧牌本来就能造成的伤害算作新购买收益。空购买的增伤和花费均为0，不干扰比值；完全无法消费时参考价为0。已有牌因新buff得到的增伤包含在分子中。它是组合平均效率，**不是严格的多1金币边际导数，也不是实际5槽刷新的概率期望**。

对旧聚合输出不需要重跑落位：收益总和直接从已存的完整增伤直方图求得；按剩余张数/费用/空格做DP，精确补出实际花费分布。对采样、截断、限为单张的输出拒绝发布“全池组合参考价”。

## 已有数据确实可用，但需隔离旧模型

原full模型含老板娘等复杂效果。根据已存数据：开局3金币平均实际消费2.842金、增伤20.212，约7.112伤害/金；开局5金币平均实际消费4.776金、增伤36.521，约7.647伤害/金。第3回合三虎约5.699，第4回合五牌约5.844，第5回合七牌约3.124。

这些旧数据已整理保存，但不能冒充后来用户要求的白板规则。所以补算了8个refresh_v1参考局面，全部完整穷举，无采样/截断；每个局面均保存原始输出和精确支出分布。没有拿不同棋盘的结果直接相减当成金币边际收益。

单次补算核耗时分别约12.00、10.82、9.31、6.19、3.50、0.413、0.052、0.001秒；离线运行即可，使用参考表时不重复穷举。

初始粗表可取空盘7.2/5.9/4.6/3.3/1.9；有现成羁绊/增益牌时参考对应已有牌局面。后期已有加成时补牌效率可以高于同期空盘，不能机械只按剩余回合乘一个固定系数。参考只覆盖这8种抽象局面，未称覆盖所有棋盘、所有预算；同样空格但不同牌组的价值仍可能不同。

这批表保留组合收益的成型加成，故与此前单牌中位数有明显差异。不是根据单边100局成绩反向调参得到，也没有以“估价更高”宣称策略一定更好。默认旧首版仍可复现；要使用新表可显式传--reference，先继续讨论或再做单边对照。

## 工具与验证

新增intelligence_gold_value.py / gold_value.py，生成可审计表、历史对照、实际支出分布和精确整数分子分母。策略参考读取兼容gold_value字段与旧median字段，拒绝未完成的全池表或规则不一致的表。

```bash
# 只整理旧记录，快速完成
python tools/intelligence_gold_value.py --output /tmp/old-gold-values.json
# 补算白板参考，保存8个全量局面
python tools/intelligence_gold_value.py --recompute --seconds 60 --output /tmp/pool-gold-values.json
# 显式使用新表做单边对照（本次没有自动重跑或改权重）
python tools/intelligence_single_player.py --games 100 --reference /tmp/pool-gold-values.json --output /tmp/new-values-regression.json
```
