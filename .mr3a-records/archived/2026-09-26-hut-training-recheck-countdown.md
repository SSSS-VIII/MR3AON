# 小屋修炼：领取成果后回到倒计时挂起

## 现象 / 需求

领取修炼完成并点「继续修炼」后，任务直接回主页 `StopTask`，不登记延后；同一会话里小屋任务被消费掉，直到下次 bootstrap 才再进。

## 原因

`确定继续修炼` 的 next 在处理饭团不足弹窗后是 `小屋返回`，从未回到 `进入了忍者小屋页面` → `忍者小屋还在修炼`。

今日 09:24 路径：`修炼完成` → `确定碎片` → `确定继续修炼` → `小屋返回` → `小屋修炼回到主页面`，无 `ScheduleDeferredTask`。

## 改动

`确定继续修炼` 成功后改为进入 `进入了忍者小屋页面`，重新判断完成 / 空闲 / 倒计时并挂起。

## 验证

- `test_hut_training_rechecks_countdown_after_continue`
- 实机：领取并继续后应出现 `延后任务已登记: key='小屋修炼'`
