# 每日悬赏免费后再花 50 买一次

## 需求

每日悬赏顶部领取按钮原先只处理「每日首次免费」。领完后按钮会变成花 50 再领一次，再往后变成 80。希望每天：免费领一次，再花 50 买一次，不买 80。

## 改动

在 `每日悬赏主页面` 的 JumpBack 链路上，紧挨原有免费节点之后补充两次识别，均复用现有 ROI：

- `每日悬赏花费50领取`：与 `每日悬赏每日首次免费` 同 ROI，OCR `50`，点领取按钮。
- `每日悬赏花费50确认`：与 `每日悬赏首次购买免费` 同 ROI，OCR `50`，点购买确认。

顺序为：免费确认 → 50 确认 → 免费按钮 → 50 按钮 → 关闭购买叉叉。按钮变成 80 后不会命中上述节点，随后走叉叉关闭并继续后续悬赏流程。

## 验证

- Pipeline JSON 解析通过。
- 未改 80 相关节点；依赖按钮文案从 50 变为 80 自然停买。
