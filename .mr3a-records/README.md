# 本地工作记录

这里是项目的主要开发记录目录，排查、验证、整理及代码改动都在此记录。开始工作依次读本页、`workflow.md`、`current-work.md`、`roadmap.md`，再读相关归档；运行验证前先读 `test-environment.md`。根目录 `AGENTS.md` 是 Agent 的读取入口，这里的详细文档由它指引读取。

- [workflow.md](workflow.md)：长期有效的开发流程、运行约束和历史决策入口。
- `current-work.md`：当前工作的分组、记录入口、已知问题和交接清单；工作收口后同步更新。
- `roadmap.md`：当前工作进展和下一步，只保留简短状态。
- `test-environment.md`：日常需要查看的测试环境、启动方式和隔离规则。
- `archived/`：已经告一段落的工作的详细记录，平时不需要频繁查看；测试环境不放在这里。

归档采用中文「现象/需求、原因、改动、验证」结构；明确区分代码已写、静态检查通过、实机已验证与仍待实现。历史结论可能被后续修改替代，以当前代码和最新验证交叉确认。
